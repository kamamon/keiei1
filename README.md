# 球団社長 — プロ野球経営シミュレーション

架空の12球団から1つを選び、球団社長として**チームづくりと経営のすべて**を動かすブラウザゲームです。
`index.html` 1ファイルだけで動くので、GitHub Pages にそのまま置けば公開できます。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作ります（例：`kyudan-shacho`、Public）。
2. 「Add file → Upload files」で、このフォルダの中身（最低限 `index.html`）をアップロードして Commit します。
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save。
4. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

ローカルで遊ぶだけなら `index.html` をブラウザで開くだけでも動きます。

## セーブ

- 毎週の進行時に、ブラウザ（localStorage）へ自動保存します。
- 「セーブ・設定」から3つのスロットへの保存と、ファイルへの書き出し・読み込みができます。別の端末で続きを遊ぶときはファイルを使ってください。

## 改造する人へ

`index.html` は `src/` のファイルをまとめて作っています。

```
src/core/   ゲームの仕組み（試合・選手・経営・ドラフトなど。画面に依存しない）
src/ui/     画面
src/style.css, src/template.html
build.js    node build.js で index.html を作り直す
```

登場する球団・企業・人物はすべて架空です。
