# 球団社長 — プロ野球経営シミュレーション／メジャーリーグ経営シミュレーション

架空の12球団（日本のプロ野球）または架空の30球団（メジャーリーグ）から1つを選ぶか、**カスタムスタート**で自分だけの球団を立ち上げ、球団社長として**チームづくりと経営のすべて**を動かすブラウザゲームです。
`index.html` 1ファイルだけで動くので、GitHub Pages にそのまま置けば公開できます。

## 遊ぶ

GitHub Pages を有効にすると、 **https://kamamon.github.io/keiei1/** で遊べます。
メジャーリーグ版から始めるときは **https://kamamon.github.io/keiei1/mlb.html** を開きます（タイトルの切り替えでどちらも遊べます）。
`index.html` をダウンロードしてブラウザで開くだけでも動きます。

## GitHub Pages を有効にする

1. このリポジトリの **Settings → Pages** を開きます。
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save。
3. 1〜2分後、上のアドレスで公開されます。

## セーブ

- 毎週の進行時に、ブラウザ（localStorage）へ自動保存します。
- 「セーブ・設定」から3つのスロットへの保存と、ファイルへの書き出し・読み込みができます。別の端末で続きを遊ぶときはファイルを使ってください。

## 改造する人へ

`index.html` は `src/` のファイルをまとめて作っています。

```
src/core/   ゲームの仕組み（試合・選手・経営・ドラフトなど。画面に依存しない）
src/ui/     画面
src/style.css, src/template.html
img/        Canva で作った写真（設定で「写真」にしたときに使う。ここにある画像を build.js が自動で使う）
            場面のイラストは src/ui/20_ui_illust.js で描いている
build.js    node build.js index.html で index.html と mlb.html を作り直す（引数なしなら dist/ に作る）
            リーグごとの違いは src/core/01_league.js（データ表の入れ替え）と src/core/15_mlbrules.js（メジャー版の決まりごと）
```

登場する球団・企業・人物はすべて架空です。
